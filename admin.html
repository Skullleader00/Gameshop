⚠ ยังไม่ได้ตั้งค่า Firebase

ทำตามขั้นตอนด้านล่างเพื่อเชื่อมต่อกับ Firebase ของคุณ

วิธีตั้งค่า Firebase (ทำครั้งเดียว)

ทำตามขั้นตอนนี้เพื่อให้ข้อมูลซิงค์ข้ามอุปกรณ์

STEP 1 — สร้าง Firebase Project
  1. ไปที่ console.firebase.google.com
  2. คลิก "Add project" → ตั้งชื่อ → Create
STEP 2 — เพิ่ม Web App
  1. ใน Project → คลิกไอคอน </> (Web)
  2. ตั้งชื่อ App → Register → คัดลอก firebaseConfig
STEP 3 — เปิด Realtime Database
  1. ซ้ายมือ → Build → Realtime Database
  2. คลิก "Create Database" → เลือก Region → Start in test mode
STEP 4 — เปิด Authentication (Email)
  1. Build → Authentication → Get started
  2. Sign-in method → Email/Password → Enable
  3. Users tab → Add user → ใส่ email+รหัสผ่านของคุณ
STEP 5 — แก้ไขไฟล์ firebase-config.js

เปิดไฟล์ firebase-config.js แล้วแทนที่ค่าด้วย config ของคุณ:

export const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "your-app.firebaseapp.com",
  databaseURL: "https://your-app-default-rtdb.firebaseio.com",
  projectId: "your-app",
  storageBucket: "your-app.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123:web:abc123"
};
STEP 6 — ตั้งค่า Database Rules

Realtime Database → Rules → แทนที่ด้วย:

{
  "rules": {
    "shop": {
      ".read": true,
      ".write": "auth != null"
    },
    "products": {
      ".read": true,
      ".write": "auth != null"
    }
  }
}
STEP 7 — ตั้งค่า Secret Key (สำคัญมาก)

เปิดไฟล์ admin.html แล้วหาบรรทัดนี้แล้วเปลี่ยนเป็นคีย์ของคุณเอง:

const SECRET_KEY = 'my-secret-2025'; // เปลี่ยนตรงนี้!

จากนั้นเข้า Admin ด้วย URL: yoursite.github.io/admin.html?key=คีย์ของคุณ
ถ้าไม่มี ?key= ถูกต้อง จะเห็นแค่หน้า 404 เปล่าๆ

STEP 8 — Deploy บน GitHub Pages
  1. สร้าง Repository ใหม่บน GitHub
  2. อัปโหลดไฟล์: index.html, admin.html, firebase-config.js, robots.txt
  3. Settings → Pages → Branch: main → Save
  4. ได้ลิงก์ https://username.github.io/repo-name
✓ หลังจากตั้งค่าแล้ว ข้อมูลสินค้าและตั้งค่าร้านจะซิงค์ real-time ทุกอุปกรณ์โดยอัตโนมัติ
